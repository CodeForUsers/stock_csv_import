Stock Import from CSV/XLSX

Effortlessly update your inventory with bulk imports.

Done by David Carreres Gomez - Professional Odoo Development

This module allows you to import stock quantities directly from CSV or XLSX files. It is optimized for large datasets (4000+ products) and handles errors gracefully.

Key Features

Multi-Format Support

Upload both CSV and XLSX files. The system automatically detects the format.

High Performance

Batch processing ensures that even large files (4000+ rows) are imported quickly without timeouts.

Safe Transactions

The system validates every row. If an error occurs, it is logged, but valid rows can still be processed (configurable).

How to Use

  1. Go to Inventory > Operations > Import Stock.
  2. Upload your CSV or Excel file.
  3. Ensure columns for SKU and Quantity are present.
  4. Click Import.
